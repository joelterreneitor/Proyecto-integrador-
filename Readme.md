# Módulo: Base de Datos (PostgreSQL) - Proyecto Integrador Extratron

## Descripción del Módulo
El módulo de **Base de Datos** representa la capa de persistencia y almacenamiento estructurado de la plataforma *Extratron*. Su propósito es modelar, desplegar y administrar las tablas relacionales en **PostgreSQL** para resguardar la información extraída, los datos geográficos de catastro y los registros del sistema, garantizando la disponibilidad para las APIs y el Dashboard.

## Responsable de tablas y datos 
* **Integrante:** Joelsexyboy69 (Diseño de Esquemas, Importación Masiva CSV DENUE, Configuración DBeaver y Servidor)

## Alcance Personal
* Gestión de entornos de desarrollo local e integración a servidor remoto con **DBeaver**.
* Pruebas de virtualización y contenedorización con **Docker**.
* Modelado y creación de tablas de prueba y tablas definitivas para almacenamiento geográfico.
* Procesamiento e importación masiva de grandes volúmenes de datos (Dataset **DENUE - INEGI** ~1 millón de registros).
* Generación de consultas DDL y DML para validación de datos e integridad relacional.

## Herramientas y Entorno de Trabajo
* **DBMS:** PostgreSQL 16
* **Cliente de Base de Datos:** DBeaver Community Edition
* **Contenedores:** Docker Desktop (Evaluación y pruebas)
* **Fuente de Datos:** Dataset DENUE INEGI Formato CSV (por el momento)
